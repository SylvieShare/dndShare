# Общая Android-дизайн-система

`designSystem` — Android library module с нативными Compose-компонентами.
Он играет ту же архитектурную роль, что `@sylvieshare/share-ui` в вебе.
Библиотека компилируется вместе с приложением; не требует загрузки кода или
ресурсов во время запуска. Минимальная версия — API 26.

## Граница

Общий модуль отвечает за оформление, состояния нажатия/выбора, зоны нажатия,
типографику и доступность. Все значения передаются обычными параметрами и
Compose-слотами. В зависимостях только Compose Foundation/Material 3.
Моделей Item/Character, API, Room, источников изображений и синхронизации здесь нет.

`androidApp` собирает предметные компоненты справочника из этих примитивов:
карточку коллекции, панель фильтров, строки предметов, просмотр и поля схемы.
Правила школ магии, уровней, публикаций, видимости и навигации принадлежат приложению.
Новый общий компонент выделяется при общей UI-ответственности, а не ради
обёртки над каждой функцией Material. При наличии подходящего примитива
экраны используют его, чтобы размеры и состояния не расходились.

## Каталог

| Android | Соответствующая роль в вебе |
| --- | --- |
| `ShareTheme`, `WebPalette` | Палитра/радиусы share-ui, продуктовый фиолетовый акцент |
| `Modifier.shareCanvas()` | Спокойный точечный фон share-ui: шаг 24, радиус 1, общий цвет границы |
| `ShareTypography` | Display Cormorant Garamond, prose Literata; UI остаётся системным |
| `Glyph`, `AppGlyph` | Те же Lucide vector paths, без растровых производных |
| `ShareWorkspaceHeader` | Общая шапка: Surface, нижняя граница, тень, центрированное содержимое максимум ContentMax и слот RowScope |
| `ShareAction`, `ShareSearch` | ActionButton, строка поиска/поле ввода |
| `ShareTile` | BaseTile, оболочка коллекции или статьи; optional `accent` соответствует TileAccentStrip |
| `ShareContentRow` | ContentRow: метрика, имя, второе имя, подстрока, маркеры |
| `ShareBadge` | Малые цветные маркеры/счётчики |
| `ShareSection`, `ShareDetailSection` | SectionLabel/DetailSection, в том числе раскрывающаяся секция |
| `ShareIconNavigation` | IconNavigation: именованные разделы, скользящее фиолетовое выделение и доступные вкладки |
| `ShareMorphState`, `ShareMorphSource`, `ShareMorphDialog` | MorphSheet/MorphEditorShell: перенос исходного Compose-поддерева в модальное окно, адаптивное превью/форма, затемнение и аппаратное размытие |
| `ShareBalancedColumns` | Адаптивные колонки, максимум три, балансировка высоты без изменения порядка чтения |
| `ShareStats` | Карточки параметров в области обложки |
| `ShareTable` | Читаемая таблица описания с горизонтальной прокруткой и inline-ссылками |

API конкретных компонентов находится в `src/main/kotlin/ru/dndshare/designsystem`.
Callbacks выполняют действия в приложении; библиотека не делает сетевых запросов.
Ширины/раскладку выбирает экран по доступному окну, не по модели устройства.
Зоны нажатия не меньше 48 dp; шрифты учитывают системный масштаб.
Compose-анимации учитывают системное отключение движения.

## Общие исходники и обновление

Размеры, радиусы, пороги окна и типографические роли `DesignTokens` генерируются
из [design/tokens.json](../../design/tokens.json) командой
`python3 scripts/design/tokens.py`; `--check` проверяет производные CSS/JS/Kotlin.
`ShareTypography` применяет роли с поддержкой системного масштаба.
`ShareTile.contentPadding` задаёт предметный отступ, по умолчанию общий Large;
плитка коллекции явно использует Collection.Padding.
`ShareTile.framed` управляет обводкой поверхности; безрамочные характеристики
собираются непосредственно из своего содержимого и цветной полосы.
`ShareMorphSource(key)` регистрирует исходный компонент и его актуальные границы;
`Modifier.shareAccentStrip(color)` добавляет цветовой маркер без поверхности и рамки;
`Modifier.shareMorphBackground(state)` размывает подложку на поддерживаемой ОС.
Морф хранит геометрию, анимацию и `movableContentOf` исходного компонента:
одно Compose-поддерево переносится в системный `Dialog` и возвращается на лист
с сохранением `remember`; на листе остаётся измеренный placeholder.
Ширина превью меняется на каждом кадре и вызывает реальную перевёрстку текста,
без масштабирования. Форма измеряется со стабильной конечной шириной;
progress читается в layout/draw/layer-фазах, без покадровой рекомпозиции слотов.
`ShareMorphSource.scrollPreview=false` оставляет прокрутку собственному
виртуализированному списку компонента, которому передаются конечные ограничения.
На узком окне высота прокручиваемого превью ограничена меньшим из общего
MorphPreviewMaxHeight и 45% доступной высоты; форма имеет отдельную прокрутку.
Невалидные/отсоединённые границы заменяются последними видимыми или безопасным
центральным якорем. Прерванное открытие/закрытие продолжается с текущей доли.
Данные редактора и восстановление принадлежат приложению.
`ShareContentRow` принимает слот иконки и правых маркеров, показывает метрику,
имя с английским названием и подстрочник. Геометрия берётся из List,
типографика — из row/list-ролей, а выделение использует Motion.Feedback.

Палитра и Lucide генерируются из продуктовых токенов и установленных веб-зависимостей командой
`python3 scripts/native/sync_web_design.py` из корня репозитория.
`--check` проверяет отсутствие расхождений. Генерируемые Kotlin/vector resources
коммитятся. Материальная тема использует мягкий акцент для текста и насыщенный
для залитых действий; цветовые роли и контраст сохраняются.

Шрифты из официального `google/fonts` включены в `res/font`. Происхождение
и SHA-256 каждого TTF записаны в [font-sources.json](font-sources.json).
OFL и лицензия Lucide поставляются в `src/main/assets/licenses` внутри APK.
Из этих же TTF генерируются локальные WOFF2 веба; рецепт и проверка —
[общие исходники](../../design/README.md). Для замены шрифта обновляются файл,
его запись в манифесте, лицензия и веб-производные.

## Проверка

`scripts/native/build.ps1 -Target All` собирает consumer APK, запускает unit и lint
с анализом библиотечного модуля. `DeviceTest` проверяет данные на эмуляторе;
сценарий API/PostgreSQL проверяет собранный экран на трёх форматах окна.
При изменении общего компонента проверяются все использующие его экраны.
