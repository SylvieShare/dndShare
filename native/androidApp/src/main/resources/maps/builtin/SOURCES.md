# Процедурные объекты карт

Сгенерированы из `frontend/src/features/maps/rendering/sceneObjects.js` командой
`node scripts/native/generate-map-props.mjs`. Геометрия и материалы повторяют веб.
Three.js/GLTFExporter используются только при сборке этих статичных GLB;
JavaScript и движок Three.js в APK не входят. Проверочные SHA-256 — в manifest.json.
