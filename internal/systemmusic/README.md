# System music provenance

All tracks in this system catalog were published with the
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
public-domain dedication. They can be copied, modified, distributed, and used
commercially without attribution. Source links and hashes are kept here so every
S3 object remains auditable. Production object keys use the immutable
`system-music/v1/<file>` prefix; binaries are not stored in Git or embedded in
the application. The verified catalog was uploaded to the production S3 bucket
on 2026-08-15.

Verified local source files can be uploaded with:

```bash
go run ./cmd/system-music-upload -source-dir /path/to/tracks
```
