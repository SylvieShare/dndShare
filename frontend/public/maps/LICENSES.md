# System map assets

- `cavern.png`: **Cavern Battlemap** by Ferrin, CC0 1.0.
  Source: https://opengameart.org/content/cavern-battlemap
  Original: https://opengameart.org/sites/default/files/cavern_0.png
  Retrieved 2026-09-20. Original 2000 × 2000 PNG, 50 pixels per cell.
- `city.svg`: original DnD Share vector cartography, generated reproducibly by
  `scripts/maps/generate-city.mjs`. No third-party artwork.
- The six editable map layouts and procedural material textures are original
  DnD Share assets. They contain no third-party tiles or illustrations.

System maps are copied into sessions; user changes do not alter the originals.
