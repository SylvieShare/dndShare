# D&D condition icons

SVG icons for common D&D states. They are stored in `frontend/public/static/conditions` and can be referenced from the app as `/static/conditions/<name>.svg`.

| State | File |
| --- | --- |
| Без сознания | `unconscious.svg` |
| Выход из строя | `incapacitated.svg` |
| Глухота | `deafened.svg` |
| Захват | `grappled.svg` |
| Испуг | `frightened.svg` |
| Невидимость | `invisible.svg` |
| Обворожение | `charmed.svg` |
| Обездвиженность | `restrained.svg` |
| Окаменение | `petrified.svg` |
| Отравление | `poisoned.svg` |
| Паралич | `paralyzed.svg` |
| Распластанность | `prone.svg` |
| Слепота | `blinded.svg` |
| Шок | `stunned.svg` |
