# Cyberpunk RED

Системный модуль в разработке. Публичная регистрация включается после готовности
листа, визарда и данных. Основной источник — предоставленная пользователем
русская книга 1.25, SHA указан в [описи](../../../../../../docs/cyberpunk-red-sources.md).

`catalogue.js` — стабильные ключи и рабочий глоссарий.
`creationTables.js` — таблицы характеристик (стр. 74–77) и навыки ролей (86–89).
`creationValidation.js` — проверка явного профиля, специализаций и грантов.
`creation.js` — три стратегии генерации и начальная сборка документа;
комплекты, покупки и ролевые выборы ещё должны пройти общий финализатор.
`derived.js` — HP, Humanity и числовые проекции.
`checks.js` — чистые расчёты проверок и базового попадания в тело.

Функции ничего не пишут на сервер. Пока `assembleRedBaseDocument` не учитывает
комплекты, покупки и все настройки роли, его нельзя подключать как финальный
продуктовый create action. Расчёт по исходным STAT также не заменяет расчёт
эффективных характеристик после экипировки.

Ссылка на перевод не означает, что он официальный. Числовые правила и
сомнительные формулировки сверяются с изображением таблиц и официальной errata.
