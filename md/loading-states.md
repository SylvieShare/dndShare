# Состояния загрузки

Frontend использует общие компоненты `@sylvieshare/share-ui`:

- `LoadingState` — первая загрузка страницы, раздела, диалога или результатов
  поиска. `compact` оставляет небольшую строку, `fill` заполняет доступную область.
- `LoadingIndicator` — операции в кнопках, загрузка файлов, обложек и буферизация
  музыки. `xs` и числовой размер подходят для небольших контролов; `inline`
  располагает подпись рядом. Подпись обязательна; в кнопке с собственным текстом
  декоративный индикатор получает `aria-hidden`.
- `SkeletonBlock` — только части уже известной структуры. В листе персонажа
  сохраняются настоящие секции и строки навыков, способностей и инвентаря.
  Произвольные наборы плиток до получения списка или шаблона не используются.

Индикатор — простое тонкое кольцо с вращающимся сегментом в цвете темы.
Все состояния поддерживают `prefers-reduced-motion`.
`LoadingState` помечает область `aria-busy`, а индикатор предоставляет `role=status`.
Кнопки `FormActionButtons` и `ConfirmDialog` показывают маленький индикатор при
`loading`, сохраняя существующие подписи и правила блокировки действий.

## Где применено

| Область | Первая загрузка / ожидание | Известная структура |
|---|---|---|
| Списки персонажей и сессий, приглашение и вступление | LoadingState вместо произвольных карточек | Полученный список |
| Лист персонажа и его модальное окно | LoadingIndicator до ответа с шаблоном; ошибка с повтором | Скелетоны конкретных строк и настоящая раскладка |
| Справочник, словари, просмотр объекта | LoadingState; ошибка с повтором | Догрузка внизу сохраняет готовые результаты |
| Главная справочника | Раздельные состояния источников и разделов; старые ответы сменённого источника игнорируются | Список выбранного источника |
| Поиск и suggest-picker на desktop/mobile | LoadingIndicator/LoadingState; пустой результат только после завершения | Уже полученные варианты |
| Создание персонажа, повышение уровня, редакторы правил | LoadingState в загружаемой секции | Готовые поля остаются на месте |
| Сессия, мир, граф, материалы, хроника, журнал и экран игроков | LoadingState в области содержимого | Холст и уже загруженные сущности |
| Музыкальная библиотека | Отдельная загрузка библиотеки и ошибка с повтором | Буферизация выбранного трека через MusicLoadingIndicator → общий LoadingIndicator |
| Аккаунт и администрирование | LoadingState для данных; LoadingIndicator для действий | Готовые результаты |
| Изображения и загрузка файлов | Общий индикатор вместо локальных спиннеров | Ошибка/предпросмотр после завершения |
| Печатный лист | LoadingState до готовности печатных страниц | Печать доступна после загрузки |

## Переходы и исключения

Ошибка запроса не является пустым результатом и не должна оставлять бесконечную
анимацию. Повтор использует тот же запрос; быстрые смены словаря, источника и
объекта не позволяют старому ответу заменить актуальные данные. Общий
`useSuggestLoading` обрабатывает ожидание, ошибку, повтор и смену словаря для
picker-компонентов; локальные и закэшированные варианты не показывают загрузку.

Неопределённый индикатор не заменяет реальный процент загрузки файлов, прогресс
админских задач, таймеры и счётчики. Фоновый polling и синхронизация не закрывают
готовое содержимое. Статусы соединения и отсчёт отложенного автосохранения
сохраняют собственную семантику; анимация активного запроса отличается от
ожидания следующего сохранения.
