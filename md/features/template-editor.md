# Template Editor

Read this before touching `features/template-editor`.

Pages:

- `features/template-editor/pages/ViewTemplates.vue`
- `features/template-editor/pages/ViewTemplateEditor.vue`

`ViewTemplates.vue` lists templates and creates a new template via `POST /template`.

`ViewTemplateEditor.vue` currently shows a placeholder for schema v2 visual editing. The current template schema rules live in `md/features/character-editor.md`.
