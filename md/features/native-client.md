# Android-клиент с общим веб-интерфейсом

Android-приложение — Capacitor/WebView с локально упакованной сборкой frontend.
Те же HTML, CSS и JS встраиваются в Go для сайта. Сборки могут выпускаться в разное
время, но не имеют отдельных экранов и копий игровых правил.
Минимум API 26; compile/target 37. Только тёмная тема.

## Границы

Vue/share-ui владеют интерфейсом, адаптивностью, игровыми расчётами и очередью
синхронизации. Общий platform-слой выбирает хранилище: SQLite на Android,
IndexedDB в браузере. Kotlin/Compose, Filament, Room и Ktor больше не участвуют.
Нативный Java-пакет содержит только оболочку, SQLite и системную интеграцию.

Локальный origin — https://dndshare.ru. Пути /api не обслуживаются локальными
ресурсами: WebView отправляет их на production по HTTPS. Cookies остаются
HttpOnly в приватном хранилище WebView. Пароль не записывается приложением.
Проверки прав и серверная валидация сохраняются для всех операций.

## Локальные данные

platform/storage.js задаёт одинаковые get/batch/scan/clear. batch атомарен;
SQLite выполняет операции в одном выделенном потоке. Данные аккаунтов разделены
префиксом account:<id>. Отказ локального хранилища не выдаётся за успешное сохранение.

Сохраняются снимки прочитанных документов и списков, справочник, небольшие
словари, полные листы своих персонажей и неподтверждённые очереди правок.
Первый вход и первоначальная загрузка требуют сети. Сохранённая локальная
идентичность позволяет открыть загруженные данные до истечения локального
30-дневного срока; сервер заново проверяет сессию при подключении.
Ответ 401, неавторизованный checkAuth и выход очищают локальный аккаунт.

Известные снимки показываются сразу; фоновое чтение обновляет сохранённую копию.
Живое состояние сессии и /changes всегда обращаются к серверу. Если запрошенных
данных нет локально, экран завершает загрузку понятной ошибкой и повтором.

## Справочник

После авторизации, возвращения в приложение, восстановления сети и каждые пять
минут активности общий coordinator обновляет справочник через /handbook/sync.
Курсоры серверные; дата устройства не используется для отбора изменений.
Страница, metadata и её курсор записываются одной транзакцией. Прерванный обход
продолжается с сохранённой страницы. SYNC_RESET_REQUIRED запускает полный обход,
оставляя старую копию доступной до завершения. visibleIds удаляет потерянный доступ;
deleted передаётся tombstone. Фильтры редакции, книг и полей применяются локально.

Изображения и 3D-файлы не входят в начальную загрузку: они запрашиваются при
использовании. Android MediaCache хранит их в файловом кеше до 256 МиБ;
документы и очередь не вытесняются вместе с медиа. Ранее не открытый ресурс
без сети показывает штатное состояние недоступности, а не бесконечное ожидание.

## Правки и синхронизация

Используется общий [протокол документов](../document-sync.md), включая стабильные
селекторы, mutationId, версии, перенос независимых изменений и явный конфликт.
Очередь содержит собственную базу документа и группы патчей — это атомарный
восстанавливаемый локальный снимок. Перед сетевой отправкой sender ожидает
подтверждения SQLite/IndexedDB. После перезапуска очередь восстанавливается;
незанятые очереди персонажей и личных карт подбираются coordinator-ом.
Активные редакторы сохраняют владение через Web Locks.

Серверные игровые команды, совместные сессии, передачи и публикации требуют
соединения. Повтор неподтверждённого патча сохраняет исходный mutationId.
Конфликт не разрешается молчаливой перезаписью серверного документа.

## Система и 3D

Кнопка Back завершает ввод, закрывает верхний overlay, возвращает маршрут, затем
сворачивает приложение. Insets status bar/жестов передаются в общую CSS-разметку;
клавиатура меняет доступную высоту. Загрузка файлов использует системный picker,
экспорт — выбор документа Android, печать — системный PrintManager.

Библиотека карт, редактор, модельный каталог, освещение, туман и просмотр итемов
используют общий Three.js/WebGL2. Отдельного рендерера Filament нет. Worker и WASM
декодеры входят в ту же сборку. Контракты: [карты](maps.md), [модели](item-models.md),
[производительность](maps-performance.md).

## Выпуск и проверка

Интерфейс APK обновляется установкой новой версии. Сайт обновляется своим deploy.
Проверяются общий frontend build, затронутые browser-сценарии и HybridShellTest
на выделенном эмуляторе; полный набор запускается только по прямой команде.
Старый Compose-клиент не поддерживается и его тестовые таблицы не мигрируют.
