# Каталог карт и подписки

← [Игровые карты](maps.md)

Страница `/maps` и окно выбора заготовки в сессии используют один MapLibrary.
Вкладки: «Мои», «Подписки», «Каталог». Каталог бесплатный и доступен вошедшим
пользователям; роль ADMIN не требуется. Встроенных системных карт нет.

## Жизненный цикл

Новая карта — личный черновик. Его видит, изменяет и удаляет владелец.
«Опубликовать» открывает подтверждение с названием и предупреждением:
опубликованную заготовку нельзя изменить или удалить. Публикация сохраняет
тот же UUID, записывает published_at и увеличивает revision. Повтор публикации
идемпотентен; устаревшая revision отклоняется. Изменять опубликованную карту
можно только через новую личную копию. Снятия публикации и платных покупок нет.

Все опубликованные карты доступны для просмотра в каталоге. Подписка добавляет
карту во вкладку «Подписки» и позволяет открывать её в сессии или создавать
личную копию. Владелец пользуется собственной публикацией без подписки.
Повторная подписка не создаёт дубль; нельзя подписаться на свою карту.
Копия получает новый UUID и является редактируемым личным черновиком.

Карта сессии — независимый слепок document. Отписка не меняет открытые слепки,
их освещение, области, существ или трансляцию. Заготовка остаётся неизменной.
Блокировка относится к документу карты: модели по UUID по-прежнему рендерятся
в текущей общей версии, а производное превью может обновляться автором.

## Рейтинг и отображение

MapLibraryEntry — одна композиция BaseTile для плиточного и строчного вида
во всех вкладках. Показаны сохранённое превью, название, автор, размеры,
количество плиток/объектов, теги и состояние публикации. Отличаются действия:
черновик можно публиковать/удалять, чужую публикацию — подписывать/отписывать,
доступную карту — копировать или выбирать для сессии.

У публикации показаны средняя оценка и число оценок. Любой вошедший пользователь
кроме автора может поставить 1–5 звёзд, заменить или снять собственную оценку.
Подписка для оценки не требуется; отписка не удаляет оценку. Одна запись на
пользователя и карту. StarRating из share-ui обеспечивает компактный ввод,
клавиатуру, дробное среднее в readonly и reduced motion; MapRating связывает
его с API и русскими подписями.

Поиск по названию/тегу и пересечение тегов одинаковы для всех вкладок. Варианты
тегов берутся из текущего списка. Вид «Плитки / Список» сохраняется при смене
вкладки. Переключения и появление/удаление строк плавные; уходящие строки inert
и скрыты от доступного дерева. Готовые превью идут из S3; чужой пользователь
не генерирует и не заменяет снимок автора.

## HTTP и хранение

- GET `/api/maps?scope=own|subscriptions|catalogue`: компактные карточки без document.
  По умолчанию own. DTO: id, name, width/height, tileCount/objectCount, tags,
  revision, changedAt, publishedAt, owned, subscribed, author, rating,
  ratingCount, myRating и previewUrl/previewSignature/previewStale.
- GET `/api/maps/{id}`: полный документ владельцу или опубликованную карту;
  previewModelsSignature позволяет использовать загруженный каталог для снимка
  без отдельного запроса preview-context.
- POST `/api/maps/{id}/publish` с revision: публикация владельцем.
- POST `/api/maps/{id}/copy`: новая личная копия владельцу или подписчику.
- PUT/DELETE `/api/maps/subscriptions/{id}`: подписаться/отписаться.
- PUT `/api/maps/ratings/{id}` с rating 1–5; DELETE снимает оценку.
- PUT/DELETE `/api/maps/{id}` работают только с личным неопубликованным черновиком.
- POST `/api/sessions/{uuid}/maps` проверяет право использовать заготовку,
  затем создаёт независимый слепок сессии.

Приватные карты не раскрываются другому пользователю (404). Изменение публикации
и конфликт revision возвращают409, отсутствие подписки для использования —403.
Автор не может подписаться или оценить собственную карту (400).

battle_map хранит published_at; map_subscription и map_rating используют ключ
(map_id,user_id), FK на карту/пользователя. rating ограничен CHECK 1–5.
Публикация и обычная запись сериализуются блокировкой строки; проверки выполняет
сервер, в том числе для старых открытых редакторов. Отдельной копии публикации
или истории версий нет. preview принадлежит только UUID карты, system_id удалён.

Миграция008 содержит только DDL. Перед её запуском отдельная операция удаляет
строки превью встроенных карт и их S3-объекты, очищает system из source сессионных
слепков и убирает ID несуществующего встроенного источника. Документы сессий,
личные карты и их превью не удаляются. Временный CHECK защищает от повторной
записи старого системного превью между очисткой и обновлением приложения;
DDL заменяет его NOT NULL для map_id. Исходные метаданные и результат операции
сохраняются отдельно от репозитория.

## Проверки

PostgreSQL-проверка TestBattleMapPersistenceAndIsolation покрывает публикацию,
CAS, блокировку редактирования/удаления, изоляцию приватных карт, подписки,
замену/снятие рейтинга и сохранность слепков после отписки. Browser-сценарии
mapCatalogue/tags/previews/access проверяют оба вида, мобильную ширину, поиск,
рейтинг, публикацию, копирование и сохранённые снимки. Session desktop/mobile
обучение описывает выбор из трёх вкладок без создания карт во время урока.
