# Инструменты мастера

Страница `/tools` находится в группе «Для мастера» бокового и мобильного меню рядом с сессиями. Она доступна любому вошедшему пользователю: отдельной глобальной роли мастера в приложении нет. Сцены доступны для любой системы; сокровища — при выбранной D&D 5e 2014.

## Сокровища

Генератор собирает общий пул из оружия (1), вещей (2), зелий (10), доспехов (12), транспорта (13), инструментов (14) и магических предметов (19). Новый справочник с копиями предметов не создаётся. Принадлежность справочнику, продажа при создании персонажа и случайная выдача — независимые свойства.

Участие в генераторе включается в редакторе предмета, в «Цена и учёт» / «Цена, вес и использование». Включение создаёт объект `data.treasure`:

| Поле | Значение |
|---|---|
| `weight` | Относительный вес выпадения, целое 1–1000. Вес 20 даёт вдвое больший шанс, чем 10, среди подходящих записей. |
| `min_level` | Нижняя граница уровня группы, 1–20. |
| `max_level` | Верхняя граница уровня группы, 1–20, не ниже `min_level`. |

Отсутствие объекта отключает выдачу и скрывает зависимые поля. Редкость берётся из существующего `rarity`, вид — из справочника. У оружия без редкости используется обычная. Отдельный индекс ключей или таблица лута не нужны: сервер выбирает записи по наличию объекта, frontend фильтрует и делает взвешенный выбор.

`GET /api/master-tools/treasure-pool?sourceVersionId=…` требует авторизации, учитывает редакцию / стандартный content scope и возвращает только публичные или собственные предметы. Чужие личные записи не попадают в ответ. По умолчанию форма дополнительно исключает личные записи; их можно включить переключателем.

Форма задаёт уровень группы, число разных предметов (0–20), обычный / магический / смешанный состав, справочник, предел редкости и отдельный диапазон золотых монет (0–1 000 000). Зелья относятся к магическому составу. Выбор выполняется без повторов записей с помощью `crypto.getRandomValues`. Монеты выбираются равномерно из целых значений диапазона; стоимость предметов не вычитается из них. Нехватка кандидатов показывается явно, ограничения не ослабляются. Карточки открываются через обычный просмотр справочника; результат можно скопировать текстом.

Начальный пул миграции `87_master_tools.sql`: публичные магические предметы и зелья с редкостью 0–4, а также обычные переносимые вещи, оружие, инструменты и броня с флагом стартового магазина. Транспорт, артефакты и личные записи включаются автором вручную. Рекомендуемые уровни для редкости 2/3/4 — 5/11/17; веса для магических редкостей 0–4 — 20/10/4/2/1, для обычного снаряжения — 10. Это редакционные настройки приложения, **не таблицы DMG и не оценка баланса награды**. Все значения можно изменить у предмета.

Результат существует в текущей странице; переключение вкладок его сохраняет, обновление страницы очищает. Генерация не меняет инвентарь, кошелёк или сессию.

## Ночлег и странствие

21 авторская сцена находится в `journeyEvents.js`. Ночлег разделён на лагерь на природе и постоялый двор; странствие — на дорогу, дикую местность и руины. Каждое место поддерживает спокойную встречу, тайну и осложнение. Сцена содержит обстановку, выбор героев и возможное развитие. При наличии альтернативы следующий бросок не повторяет текущую сцену.

События не применяют урон, проверки или отдых автоматически. Они не являются перепечаткой книжных таблиц. Мастер определяет сложность и последствия по ситуации. Текст можно скопировать.

## Интерфейс и проверки

Форма и результат размещены в двух колонках с независимой прокруткой на широком экране; на узком идут последовательно. Используются общие `BaseTile`, `SlidingTabs`, form-controls, `ActionButton`, `SectionList` и справочные строки. `ActionButton` опубликован в share-ui 0.19.0; локальные кнопочные примитивы не дублируются.

Тесты проверяют исключение неподходящих предметов, веса, отсутствие повторов, границы монет, недостаточный пул, все комбинации сцен и отсутствие немедленного повтора. SQL проверяется вместе с миграцией магических предметов на локальной временной PostgreSQL с rollback.
