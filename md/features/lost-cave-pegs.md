# Посадка монтажных вставок Lost Cave

Проверка каркаса LC-060 выявила проникновение прежней упрощённой вставки
LC-001 в стенки до0,702 мм. Её верхняя часть слишком широкая для нативного
профиля паза. Родная полость и слот каркаса сохраняются.

## Исправление

Для стандартной ячейки35 мм остаётся одна простая усечённая пирамида:
ширина34,3 мм сверху и22,75 мм снизу. Высота и центр прежнего монтажного
выступа сохраняются. Нестандартная ширина требует отдельного рассмотрения.
Модель без упрощённых вставок не получает новую вставку; это сохраняет
восстановленную полость LC-034 и нативные объекты без монтажной части.

[fitted_cave_pegs.mjs](../../scripts/maps/fitted_cave_pegs.mjs) добавляет
маленький монтажный меш в исходный GLB. Сжатые буферы каменного тела,
координаты, нормали, UV, изображения и материалы сохраняются побайтно.
Старый монтажный меш исключён из сцены; источники, UUID и метаданные
размещения остаются прежними. Метка профиля в extras делает повтор
идемпотентным. Новый shadow готовится из исправленного LOD.

```bash
node scripts/maps/prepare-fitted-cave-pegs.mjs LC-001
```

Подготовка читает текущую детально проверенную модель, сверяет SHA и размеры,
пишет результат в models/collections/lost-cave/peg-fit/LC-001 и декодированные
копии для Blender. После проверки превью, посадки, обеих детализаций и теней
пакет собирается через package-masonry с recipe=lost-cave-peg-fit-v1.
Подтверждение публикации использует confirm-reviewed-model с
--assets=<папка upload> и свежим MCP-снимком. Проработка текстур не меняется.
