# Поддержка механик справочных записей

Оценка относится к записи справочника любого типа: вещам, магическим предметам,
оружию, доспехам, способностям, заклинаниям и остальным каталогам. Она описывает
покрытие правила средствами сайта и не влияет на расчёты или доступность предмета.
Экземпляры на листах используют оценку исходной справочной записи.

## Статусы

| Значение API | Подпись | Значение для пользователя |
| --- | --- | --- |
| `unreviewed` | Не оценено | Покрытие ещё не проверяли; это исходное состояние всех существующих и новых записей. |
| `full` | Полностью | Все применимые механики поддержаны. Явный выбор игрока и предусмотренное правилами ручное подтверждение допустимы. |
| `partial` | Частично | Часть механик поддержана, остальные нужно учитывать вручную. |
| `none` | Не автоматизировано | У записи есть игровые механики, но сайт их пока не применяет. |
| `not_applicable` | Не требуется | У записи нет механик, требующих автоматизации. |

Количество зависимостей, тип справочника и наличие описания не определяют статус
автоматически. Изменение правил также не меняет оценку автоматически: при разборе
или изменении механики автор должен пересмотреть статус вместе с ней.

`requiresPlayerInteraction` — независимая отметка «Другие игроки». Применение
затрагивает персонажа другого игрока и требует согласования или действий на его
листе. Полная поддержка совместима с этой отметкой. Обычный выбор цели или
подтверждение мастером сами по себе не означают межигроковое взаимодействие.
`automationNote` — необязательное пояснение об ограничениях, до 1000 символов
обычного текста. Для частичной поддержки полезно назвать конкретную механику,
которая остаётся ручной.

## Отображение и редактирование

`ItemAutomationBadge` выводится в нижней строке `HandbookItemDetail` рядом с
редактированием и ID. Статус имеет текст и иконку; цвет не является единственным
признаком. Комментарий доступен при наведении на статус. Нажатие открывает
пояснение через общий `BasePopover`, в том числе на телефоне и с клавиатуры.
Читатель видит ту же оценку и пояснение, без права редактировать запись.

`ItemEditModal` использует единый свёрнутый раздел `ItemAutomationEditor`
«Поддержка механик» в основной колонке всех редакторов. Подписи полей имеют
подсказки при наведении. Права совпадают с правами изменения записи: её автор
или администратор справочника/сайта. Свои материалы не запрашивают источник.

## Хранение и API

Миграция `108_item_automation.sql` добавляет к `dndshare.item` общие колонки
`automation_status`, `automation_note`, `requires_player_interaction`.
Статус — `text` с ограничением `CHECK`, то есть закрытый набор значений на уровне
БД без отдельного PostgreSQL enum-типа. Это метаданные сайта вне `item.data` и
вне повторяемых JSON-схем отдельных справочников. Индекс не добавлен: запросов
фильтрации по оценке пока нет.

DTO Item, HTTP создание/обновление и MCP `handbook_item_create/update` используют
верхнеуровневые camelCase-поля. Пропущенные поля при обновлении сохраняются,
пустой комментарий и `false` явно очищают соответствующие значения. Некорректный
статус или слишком длинный комментарий отклоняются до записи; метаданные и
содержимое сохраняются одним SQL-запросом с общей проверкой владельца.

## Проверки

`item_automation*_test.go` проверяют валидацию, повтор миграции, исходное состояние
старых записей, чтение метаданных, права, сохранение пропущенных значений и явную
очистку. PostgreSQL-проверка запускается с `DNDSHARE_ITEM_AUTOMATION_TEST_DSN`
только на одноразовой локальной БД `dndshare_test_*`.
Frontend: `itemAutomation.test.js`, `ItemAutomationBadge.test.js` и браузерный
`tests/weapon-charges/item-automation.spec.js` проверяют desktop/mobile,
сохранение через настоящий редактор, независимость отметки и режим чтения.

## Оценки автоматизации каталога

[Аудит всех 244 магических предметов](../magic-item-automation-audit.md) выполнен 12 сентября 2026 года.
Миграция 109 сохраняет 34 оценки «Полностью», 26 «Частично» и 184
«Не автоматизировано» с индивидуальными комментариями; восемь записей имеют
отдельную отметку взаимодействия с другими игроками.
