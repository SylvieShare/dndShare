# Общий blur и потерянное production-свойство

Статус: исторический отчёт от 2 ноября 2026 года.

Причина отсутствия размытия нашлась при сравнении опубликованного CSS с dev:
после оптимизации правило шапки содержало один -webkit-backdrop-filter, без
стандартного backdrop-filter. В Chromium/Яндексе computed значение становилось
none; оставалось затемнение. Перестановки слоёв сами по себе этого не исправляли.
Предыдущие проверки под Vite dev подтверждали другую сборку.

Существующий AppModal уже удерживал оба свойства inline после анимации,
а MorphSheet размывал свой background target через обычный filter. Из этих
реализаций извлечён нейтральный API share-ui v0.48.0: BlurBackdrop,
backdropBlurStyle, applyBackdropBlur и blurFilter. Подложка декоративна, не
перехватывает ввод; границы, маска и tint задаются публичными CSS variables.
AppModal и BaseTile glass используют один конструктор; механизм владельцев
background blur морфа не меняется. Нет копирования содержимого листа, JS-
отрисовки при прокрутке или зависимости библиотеки от игровых моделей.

Шапки workspace и создания персонажа подключены к общему компоненту.
Фильтр остаётся JS inline-style после повторной минификации в consumer.
Радиус и остальные визуальные параметры сохранены. Остальные локальные
CSS-поверхности переводятся на этот API при затрагивании, без массовой смены
их дизайна в данной задаче.

Новая проверка production воспроизвела три ошибки none до исправления и
прошла после него на 390/834/1440: общий хедер, реальная навигация в лист,
возврат и создание. Сравниваются фоновые кадры blur → none → blur.
Отдельно установлен и проверен настоящий архив неизменяемого Git tag;
его SHA-512 сравнен с lock-файлом, а dist — с release commit библиотеки.
Временный file-локатор не оставляется в итоговом consumer.

Проверки библиотеки ограничены затронутыми модулями: 85 unit-кейсов,
production build с colors/sidebar проверками, built-browser сценарий изменения
радиуса, кликов сквозь подложку, glass → solid и AppModal после окончания
анимации, pack dry run. Полный проектный набор не запускался.
В Яндекс Браузере 26.10 на Windows опубликованный старый frontend дал none
во всех трёх форматах, production preview установленного v0.48.0 — blur(16px),
без pageerror. Прошли девять dev-сценариев, 13 consumer unit и production build.
Wiki проверена. Native-часть предыдущего полного парного отчёта наследуется
по неизменённым native/API/driver/matrix хешам и одинаковым palette tokens
библиотеки. Параметры оформления не менялись: production теперь восстанавливает
предусмотренный контракт. Текущий эмулятор занят другим UI-прогоном; его не
прерывали. Доказательства наследования — native-inheritance.json в артефактах.
Native/backend код этой задачи не меняется.

Во время работы в старой копии появились посторонние правки Android-карт.
Они сохранены; только собственные frontend-правки перенесены с проверкой хешей
в отдельный worktree на C. Фикс и его lock/dependencies не затрагивают ту задачу.
