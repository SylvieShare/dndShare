# Интеграция Cyberpunk RED — 16 ноября 2026

Статус: исторический отчёт. Актуальное поведение описывает контракт фичи.

Реализованы системный справочник/словари, три метода создания, восемь шагов
визарда, адаптивный лист, печать и команды игровой механики.
Текущий контракт и границы решений ведущего — [RED](../features/cyberpunk-red.md).

## Состав и проверка

Пакет: 582 записи в 18 категориях; 26 словарей, 298 значений. Все записи имеют
устойчивые ключи и страницу источника. Полный пользовательский PDF хранится
в `C:/Projects/dndshare/docs`, исключён из Git и релиза.

- 83 теста чистых правил/создания JS прошли: 10 ролей × 3 метода, комплекты,
  специализации, бюджеты, оружие, защита, IP, препараты и комбинации имплантов.
- 5 целевых Vitest-проверок прошли: восстановление команды RED, изоляция
  аккаунтов, конфликт и существующие массовые операции сессии.
- 13 Playwright-сценариев прошли: RED на 390/840/1440, редактирование/reload,
  серверный путь броска, создание и печать; регрессии меню участников,
  выбора, массового урона/IP и подготовки боя.
- `python scripts/test.py db` прошёл на изолированном PostgreSQL 16,
  `127.0.0.1:55439/dndshare_test_red`. Профиль исполнил Go tests, vet и build.
  Production DSN для тестов не использовался.
- HTTP RED проверен реальным handler: доступ владельца/ведущего, отказ
  постороннему, потерянный после commit ответ, повторная квитанция,
  однократный расход патрона/LUCK, применение урона через SP и отсутствие
  D&D `values.hp` в документе RED.
- Frontend build, eslint bindings, design/color/bundle checks и строгая wiki
  прошли. Печатный PDF отрендерен и просмотрен: 3 страницы без обрезанных блоков.
- Операторский installer: 2 unit-теста preview/expectedHash/error прошли.

Артефакты локального визуального просмотра:
`C:/Projects/dndshare/build/cyberpunk-red-review`. Браузерные трассы находятся
в `frontend/test-results` рабочей копии. Проверка физического Android-устройства
в этот прогон не входила; используется тот же Vue и та же платформа хранения.

## Выпуск

Публикация выполняется штатным Windows release coordinator из чистой копии
зафиксированного commit. После readiness пакет справочника устанавливается
через MCP `cyberpunk_red_install` с предварительным просмотром и expectedHash.
Фактические SHA, версии и подтверждение публичных endpoints фиксируются
после публикации в этой записи и release-артефактах.
