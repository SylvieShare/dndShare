# Шапка и сабхеадер списка персонажей — 29 октября 2026

Статус: исторический отчёт. Текущие контракты находятся в адаптивном дизайне,
нативном клиенте и Android design system.

## Поведение

Заголовок «Персонажи» и кнопка создания находятся в сабхеадере во всех трёх
форматах окна. В основной строке списка — DnD Share; компактная строка сохраняет
контекст системы/редакции. Повтор заголовка убран. Поиск и карточки прокручиваются
под шапкой; сабхеадер и действия остаются доступными. Широкая композиция выровнена
по центру и ширине содержимого.

Подложка основной шапки прозрачная и затемнённая. Blur и затемнение затухают за
сабхеадером до прозрачности; его поверхность, текст и кнопки рисуются отдельно
и остаются чёткими. Общие параметры заданы группой chrome design/tokens.json:
blur 16 CSS px / Android dp, tint 0,72, хвост затухания 16.

В вебе используются backdrop-filter и mask у псевдоэлемента за передним планом.
Высота общей шапки измеряется, портал списка удаляется при смене маршрута;
липкая область не оставляет дублирующую кнопку в теле страницы. Существующие
короткие переходы страницы сохраняются.

Android ShareChromeLayout измеряет слоты шапки/сабхеадера и передаёт их высоту
как внутренний отступ списка. Содержимое существует в одном экземпляре; GPU-слой
используется для размытия узкой полосы под шапкой. CPU-снимки/дублирующее дерево
компонентов не используются. API 31+ использует RenderEffect; Android 8–11 —
затемнение и градиент без blur и лишнего offscreen-буфера. Там, где содержимое
не проходит под фиксированной шапкой, её подложкой остаётся ровный фон.

Первичное ожидание списка показывает каркас; готовые записи при обновлении
сохраняются. Декодирование JSON списка Android перенесено с UI-потока на Default.
API, поиск, создание, контекстные действия и формат игровых данных не менялись.

## Проверки

- Android: 174 unit-теста, lint без ошибок, APK; native-all-title.log.
- Два instrumented-кейса ChromeLayoutTest: реальные пиксели контрастного фона
  размываются, изменение фона обновляет результат без изменения переднего плана;
  отключение blur сохраняет геометрию. Отдельно проверены 320 dp, масштаб текста
  1,6 и доступность нажатия создания. device-final.log.
- Веб: 36 scoped browser-сценариев четырёх файлов — список в трёх форматах,
  прокрутка под закреплённой шапкой, кнопка создания, отсутствие утечки портала,
  общая навигация, лист персонажа/Fold и панели сессии. browser-regression.log.
- Семь scoped unit-кейсов шапок/списка и 19 design-кейсов (один пропуск по
  окружению). Проверены единицы opacity/размеров и диапазоны токенов.
- Парный отчёт четырёх состояний/трёх форматов — 24 снимка:
  build/ui-runs/20261029T092551-1dd43abed2/review/index.html.
- После замены повторяющегося названия в главной строке на бренд заново пройдены
  Android All и unit-кейсы; финальный парный отчёт списка/меню — 12 снимков:
  build/ui-runs/20261029T094613-63d0e88b75/review/index.html. Он полностью завершён
  и не объединяет изображения разных запусков. Контроль исходников пройден.

Первый узкий сценарий списка поймал неверное общее условие visual capture,
требовавшее /api/items даже для одного /chars. Проверка теперь требует запрос
данных, соответствующих выбранным состояниям; список подтверждает /api/chars.
Незавершённый прогон не учитывался как PASS.

Проверки геометрии ожидают завершения конечных переходов страницы: промежуточный
translateX при входе не принимается за итоговый размер layout. Размытие проверено
пикселями синтетического компонента, а интерфейс — на общих настоящих данных
Go API/PostgreSQL. Ни маскировка изображений, ни подмена данных для скрытия багов
не применялись. Полный набор проекта не запускался. FPS реального устройства
этим отчётом не измеряется; визуальную приёмку выполняет пользователь.

Артефакты текущей задачи находятся в build/frosted-header/.
