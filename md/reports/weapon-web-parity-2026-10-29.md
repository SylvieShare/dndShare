# Оружие: общая композиция и эффекты веба/Android

Статус: исторический отчёт от 29 октября 2026 года.

## Изменение

Карточка компактных форматов имеет иконку 64 px рядом с именем, дистанцией,
владением и настройкой. Атака, кубики и свойства идут отдельной строкой.
Среднее окно использует две колонки. Веб-сетка принадлежит body-слоту
SectionList: разделители обычного вертикального списка не накладываются на
первую строку сетки; плашки свойств переносятся целиком.

Android открывает меню по всей карточке; троеточие удалено. Удержание включает
перетаскивание с haptic, движением соседей и прокруткой у края. Плоский keyed
layout сохраняет экземпляры карточек при переходе между колонками; сохранение
порядка не заменяет параметры предметов и учитывает параллельно добавленные записи.
Для доступности есть действия перемещения. Механики в компактных форматах
открываются в нижнем окне с nested scroll, Back и закрытием свайпом вниз.
После успешной операции окно скрывается перед общим результатом броска.

Референсы изучены в исходниках: WeaponCardView/WeaponCard, AttackDamage,
DamageDice, SystemDie, ItemResourcePips и SpellSlotSphere. Атака повторяет
подпись, размеры и заливку чипа; кубики используют общие контуры и параметры
слоёв SVG. Размытые слои готовятся вне UI-потока, ограниченный кеш хранит
готовые текстуры; до готовности используется скелетон. Пузырьки рисуются отдельно
только у видимых элементов активного окна с учётом отключения анимации.
Ячейки повторяют стекло, жидкость, блики, пузыри и расход/восстановление.
Цвет ресурса берётся из настройки владельца либо общей стабильной палитры веба.

В README и Android design system закреплено: точность интерфейса и удобство
важнее обязательной нативности каждого эффекта. Согласованные различия жестов
и нижних окон записаны в design/visual-exceptions.json.

## Обнаруженные проблемы

Android DTO не хранил встроенный SVG предмета. Добавлено поле с явным маркером
отсутствия; старый кеш один раз дозагружается полным проходом, сохраняя готовность
и офлайн-данные при сетевой ошибке. После гидратации возвращается обычная delta.

Геометрия перетаскивания должна храниться в координатах layout, без обратной связи
от трансформации движущегося элемента. Это исключает скачки между колонками.
Автоматическое раскрытие активного применения отключено для нижних окон:
подготовленная скрытая вкладка не должна сама открывать модальное окно.

Сообщение об ошибке броска исчезало по общему шестисекундному таймеру.
Ошибка теперь остаётся до повтора/закрытия; успешный результат сохраняет таймер.
Это проверено отдельным instrumented-кейсом с уже истёкшим временем сообщения.

Один интеграционный прогон прервался из-за потери ADB, без изменения приложения.
Другой выявил неточный tap теста: центр длинной карточки попал в блок механики.
Сценарий теперь открывает меню нажатием на имя. Непостоянные уведомления не
используются как доказательство доступности переброса: его проверяет действие
в панели и атомарные изменения ресурса/хроники. Старая проверка формы статов
внутри сценария оружия остановилась на поиске поля после Back; этот участок
исключён из scoped-прогона оружия. Характеристика для авторского удара задаётся
через fixture API; отдельный сценарий form-lifecycle остаётся владельцем форм.
Повторные сбои получения XML-дерева завершились перезапуском только принадлежащего
задаче AVD; общий ADB и физический телефон не перезапускались.

## Проверки

Native All: 181 unit-тест, lint без ошибок и APK. Семь уникальных instrumented-
кейсов проверили перенос между колонками, отсутствие случайного меню, нижнее
окно/свайп, офлайн-кеш и постоянное сообщение об ошибке. Web: 12 scoped unit-
кейсов, пять browser-кейсов панелей и раскрытий, production build. Восемь
тестов реестра исключений и генераторы оформления прошли проверку.
Полный проектный набор не запускался.

Реальный Compose/API/PostgreSQL: семь этапов оружия, включая авторский удар,
проверены с восстановлением фикстуры. Квитанция:
build/ui-runs/20261029T160212-ef998bbc75/receipt.json.

Парный отчёт: 12 снимков оружия и магии на 390/834/1920,
один API и одинаковые данные, проверка исходников до/после:
build/ui-runs/20261029T160541-6c768097d8/review/index.html.
