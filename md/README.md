# Wiki DnD Share

Документация для разработки и сопровождения проекта. Страницы архитектуры,
фич, API и БД описывают реализованное поведение. Аудиты и отчёты сохраняют
датированные результаты проверок; их числа не являются состоянием live-каталога.
Основные проектные инструкции находятся в [README репозитория](../README.md).
