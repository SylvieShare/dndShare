# Поддержка D&D 2014 и 2024

Статус: завершено. План отделён от wiki `md/`, описывающей только работающую систему.

## Принципы
- Одна система DND5e, две редакции, публикации независимы от совместимости.
- Конкретный item.id определяет механику. Чтение сохранённой ссылки не заменяет объект.
- Совместимость явная: item_version_compatibility; отсутствие решения не даёт доступ.
- Исходные 2014 персонажи и записи сохраняют поведение.
- Поддержка правил и полнота/автоматизация контента проверяются отдельно.
- Все выборы, поиск, счётчики, HTTP и MCP используют общий контракт.
- Сторонние изменения основной рабочей копии не включаются в выпуск.

## Контрольные сценарии
- Переключение глобальной редакции не меняет открытый или сохранённый лист.
- Изменённое заклинание имеет разные ID и формулы, общая вещь имеет один ID.
- Подключение Таши не дублирует книгу и не возвращает заменённые варианты.
- Выключение книги не удаляет старые ссылки; замена из выключенной книги не подставляется.
- Требующий адаптации объект нельзя выбрать без реализованной адаптации.
- Собственные материалы соблюдают редакцию; чужие личные материалы не раскрываются.
- 2014: половина костей хитов; 2024: все; истощение рассчитано по редакции.
