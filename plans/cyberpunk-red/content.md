# Справочник и словари RED

Предложение. [Общий план](README.md).

## Реестр источников

Для каждого источника фиксировать title/code, edition/profile, language,
URL/локальный файл, SHA-256, печатную и PDF-нумерацию страниц, errata revision,
дату проверки, доступность публикации. Номер версии PDF не становится редакцией.
В русском интерфейсе использовать согласованный глоссарий и английские aliases.
Непроверенный любительский перевод не обозначать официальным.

| Источник | Назначение | Состояние на этапе плана |
| --- | --- | --- |
| Core Rulebook | Полное покрытие правил/создания/предметов | Официальная платная версия найдена; файл ещё не получен |
| Core errata 1.25 | Исправления ранних печатей | Официальный PDF найден |
| Core character sheet | Проверка полноты полей листа | Официальные print/fillable PDF найдены |
| Free Basic Rules / Easy Mode | Начальные проверки механики | Доступно; не доказывает полноту Core |
| RU Jumpstart | Терминологическая вспомогательная сверка | Официальный PDF доступен; правила старого стартера |
| DLC / Black Chrome / Interface RED | Расширение после базы | Отдельные пакеты, отдельная проверка состава |
| Edgerunners Mission Kit | Правила эпохи 2070-х | Опциональный профиль после Core |

## Коллекции

Числа сущностей получать из сверенного manifest, а не обещать приблизительное
количество предметов. Каждая коллекция получает схему, форму редактора, компактную
карточку, полную справку, поиск, фильтры и описание уровня автоматизации.

| Коллекция | Обязательные структурированные поля |
| --- | --- |
| Роли | 10 ролей, role ability, rank progression, choices, lifepath, источник |
| Способности ролей | вид проверки, действие, ресурсы, требования, ручные решения |
| Оружие | skill, damage, ROF, hands, concealability, magazine, range table, качество, цена |
| Модификации оружия | совместимость, слоты/ограничения, эффекты, цена |
| Боеприпасы | тип, совместимость, количество, special effects, цена |
| Броня | location, SP, penalty, цена, repair; shield HP отдельно |
| Снаряжение | категория, параметры, применимые навыки, эффекты, цена |

| Кибердеки | capacity, hardware, ограничения установки |
| Программы | class, slots, activation, ATK/DEF/REZ где применимо, действия |

| Боевые приёмы | skill, требования, порядок разрешения, действие |

## Словари

Минимальная граница: 10 характеристик, полный реестр навыков Core с
параметризуемыми специализациями, группы навыков, роли/role-ability keys,
типы проверок, виды действий, локализации, ранения, категории оружия/качества,
боеприпасы, дистанции, категории киберware, виды операций и HL,
программы/NET-действия, типы транспорта, цены, валюты (eb), единицы (м/ярды),
жильё, образ жизни, культурное происхождение/языки и Lifepath-поля.

Идентичность записи — стабильный `key`, отображение — RU label + EN alias.
Skills содержат `statKey,costMultiplier,specializationKind,creationConstraints`.
Language/Local Expert/Science/Play Instrument/Martial Arts не схлопывать в одну
неизменяемую строку: у героя может быть несколько специализаций с разными рангами.
Список специализаций допускает авторские записи с явным типом.

Важные разграничения: STAT REF и DEX; базовая и текущая EMP; LUCK максимум/остаток;
ранг навыка и сумма STAT+skill; броня SP и щит HP; количество боеприпасов в
магазине и в инвентаре. UI/поиск/импорт используют одинаковые ключи.

## Формат manifest

У записи: `key,kind,sourceCode,page,errata,language,aliases,mechanics,
summary,relations,verificationStatus,automationStatus`. У каждого пакета:
`rulesProfile,revision,checksum,dependencies,expectedCounts`.
Статусы сверки: найдено → извлечено → сверено → проверено на примере → опубликовано.
Статусы автоматизации: полная / частичная с конкретным ограничением / ручная.
Не использовать статус «полная» только потому, что запись импортирована.

## Перенос

1. Сверить источники, оглавление и глоссарий. Создать перечень всех сущностей.
2. Подготовить схемы и словари; проверить ввод и отображение каждой формы.
3. Импортировать ссылки и сущности в черновой scope отдельной операцией.
4. Resolve references по ключам → ID; cross-system ссылки запрещены.
5. Проверить полноту: counts, дубли, dangling references, отсутствующие страницы,
   пустые описания, неизвестные enum, отрицательные цены/слоты и неверные кубики.
6. Прогнать примеры создания для каждой роли и методы использования предметов.
7. Опубликовать готовый пакет и прочитать обратно через HTTP/MCP и offline sync.
8. Повторить импорт: ноль лишних записей и сохранение пользовательских правок.

Для обновления использовать expected-version/checksum, patch по изменённым полям
и журнал перед/после. Rollback скрывает новую публикацию и восстанавливает только
собственные изменения, не откатывает чужие правки или созданных героев.

## Краткие памятки

Маршрут правил содержит обзор системы, создание, проверки, бой, здоровье,
человечность, NET, развитие и экономику. Это навигация и краткие подсказки к
действиям листа с ссылками на книгу, а не замена коммерческой книги.
Обучение: первый skill check, смена боеприпаса, применение урона, установка
киберware, NET-действие. Завершённые D&D-уроки сохраняют свой прогресс.
