# Следующие технические этапы Android-листа

Отложенный план. Пользователь согласовал сохранить эти пункты для следующих
участков работы; они не входят в текущий перенос контроллера состояния,
восстановления форм, свайпов вкладок и морфа характеристик.

## Игровые действия и совпадение с вебом

Выделить действия экипировки, применения заклинания и отдыха в игровой слой,
общий для трёх композиций Android. Использовать существующие транзакционные
команды сервера там, где действие меняет несколько связанных ресурсов.

Подготовить общие фикстуры расчётов для JavaScript и Kotlin: HP, КД, бонусы,
эффекты и расход ресурсов должны совпадать для одинакового документа персонажа
и справочника. Учесть D&D 2014/2024 и VTM V20. Текущий JSON данных персонажа
остаётся серверным контрактом; UI-дерево в него не возвращается.

## Обновление открытого листа и большие списки

Подключить существующие версии/изменения документа и live-события сессии,
чтобы открытый лист получал внешние правки сайта и мастера. Проверить возврат
из фона, восстановление связи и явное разрешение конфликта без потери ввода.

Перевести длинные списки инвентаря, заклинаний и дневника на ленивое отображение
со стабильными ID. Измерить прокрутку и изменение размера окна на большом
персонаже, включая Fold и увеличенный системный шрифт.

Текущее реализованное поведение описывает
[контракт Android-клиента](../md/features/native-client.md).
