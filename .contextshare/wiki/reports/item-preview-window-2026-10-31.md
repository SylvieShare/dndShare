# Окно просмотра справочной записи в Android

Статус: исторический отчёт от 31 октября 2026 года.

SharePreviewWindow повторяет композицию веб ItemViewModal: собственный scrim,
центрированная поверхность до 720 dp, на телефоне панель снизу, плавающие
закрытие и возврат, отдельный маркер, анимация и прокрутка без дублирования
заголовка. Прозрачный системный transport отвечает за focus/Back/insets;
системный dim отключён, видимый декор принадлежит приложению. На API 31+
используется cross-window blur, если его поддерживает устройство. Жест закрытия
использует общий проверенный механизм nested scroll; прокрутка тела имеет приоритет.

Лист, выбор при создании и детальная область справочника используют общий
контент. Обложки, название, второе имя, источники и показатели перенесены с
фактических веб ItemDetailHeader/CoverSummary/CoverStatCard. Для оружия,
заклинаний и магических предметов есть предметные сводки; другие типы используют
данные схемы. Поля, описания, таблицы и связи остаются доступны через schema
renderer; изображения загружаются при открытии через существующий кеш.
Редактирование и 3D остаются вне принятого Android read-only scope.

Прежняя полноэкранная страница в листе заменена окном. История ссылок сохраняет
прокрутку каждой записи, возврат не пересоздаёт лист. В создании история хранит
ID записей и переживает пересоздание Activity. Нет загрузочного spinner на весь
просмотр: используются скелетон, конечное состояние недоступной записи и повтор.
Готовые записи доступны без сети. Сводка заклинания не скрывает материальные
компоненты и условия реакции. Сложные поля сводки доступны целиком в раскрываемом
разделе «Полные характеристики»; schema dice отображается кубиком вместо ID. Названия правил получены из уже загруженных версий
источника, без выдуманного соответствия числовых ID годам редакций.

Проверки: Native All, 185 unit-тестов, lint без ошибок и APK; три instrumented-
сценария с локальной Room-базой проверили вложенную ссылку/возврат, закрытие до
исходного фона, компактный свайп и видимость редкости/зарядов магического предмета. Проверено, что окно не требует сети для данных.
17 тестов visual-инструментов, семь тестов токенов, проверка генераторов и wiki.
Веб-потребитель собран; UI веба служит неизменённым референсом.

Визуальное сравнение обнаружило лишнее общее затемнение обложки и растянутую
плашку названия. Они исправлены; тело просмотра использует роль 14/22,
согласованную с веб-описанием, без изменения остальных богатых описаний.
Размеры и иконки взяты из веба; Lucide paths получены общим генератором.
